# Multi-Client Chat Server

A multi-client chat server written in C++ as a systems programming learning project.

The goal of this project is to better understand how networked applications work internally by building a TCP chat server from scratch and implementing the architecture step by step.

This project is being developed using Linux sockets through WSL while implementing everything manually.

## Features

Implemented:

* TCP server setup
* TCP client setup
* IPv4 socket creation
* Address binding
* Listening for incoming connections
* Client acceptance loop
* Client address retrieval
* Client-server connection establishment
* Basic connection logging
